# Digital-Design-SystemVerilog
SystemVerilog RTL design repository featuring FSMs, digital circuits, and verification testbenches. Simulated using Icarus Verilog on EDA Playground with waveform analysis in GTKWave.

# Digital Design using SystemVerilog

This repository documents my journey of learning **RTL design and digital system design** using **SystemVerilog**.

The repository contains hardware design projects, finite state machines (FSMs), and verification testbenches developed while practicing digital design concepts. Each project includes synthesizable RTL, a simulation testbench, and supporting documentation where applicable.

## Development Environment

- **Language:** SystemVerilog
- **Simulator:** Icarus Verilog (iverilog)
- **Waveform Viewer:** GTKWave / EPWave
- **Platform:** EDA Playground
